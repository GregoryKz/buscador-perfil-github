Token pessoal do GitHub

Sem token, o GitHub libera 60 consultas por hora para a sua rede. Com um token, são 5.000 por hora, o que dá para conferir a turma inteira.

  1. Crie um token clássico sem marcar nenhuma permissão.
  2. Cole o token abaixo e salve.

O token fica salvo só neste navegador e é enviado apenas para api.github.com.
